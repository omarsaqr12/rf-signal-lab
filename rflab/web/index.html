Modulation

Signal parameters

Symbol rate = sample rate ÷ samples per symbol. Frame length sets both how much statistical evidence you have and how much time-accumulating impairments (CFO, clock drift) get to do damage.

Receiver processing

These are receiver choices, not channel effects. Turning timing recovery off makes the receiver sample on the nominal grid, which is what exposes a static timing offset instead of quietly absorbing it.

Impairment chain

Applied in the order a real signal meets them: transmitter → channel → over the air → receiver LO → clock → thermal noise → receiver analog → ADC.

Clean → impaired

Constellation after each stage of the chain, with the error each stage added.

Display

Short window: sharp in time, blurry in frequency. Long window: the reverse. They cannot both be sharp — that is the uncertainty principle, not a limitation of the plot.
